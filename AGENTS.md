# AGENTS Documentation

## Abstract

The AGENTS documentation enumerates all agent definitions employed across the Skills Bundle, detailing their responsibilities, supported tools, usage guidelines, and example prompts. Agents are grouped by functional domain providing a coherent reference for developers extending or customizing the skill ecosystem.

## Introduction

The `AGENTS.md` file details the available agent definitions, their responsibilities, and how they interact with the Skills Bundle. It serves as a reference for developers extending or customizing agents.

## Methodology

Each agent entry includes:
- Name and scope.
- Supported tools.
- Usage guidelines.
- Example prompts.

Sections follow the academic‑writing template to ensure consistency and readability.

## Results

* Clear, structured documentation of all agents.
* Uniform formatting across the repository.

## Discussion

Standardized documentation facilitates onboarding of new contributors and improves maintainability. Future updates should adhere to the same template.
